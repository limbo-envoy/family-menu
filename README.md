# 家里吃什么

一个家用点菜和菜谱记录小程序。第一版先用微信本地存储，适合自己家里或朋友小范围试用。

## 第 1 步：安装工具

下载并安装微信开发者工具，然后选择“小程序”项目。

微信官方入口：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

## 第 2 步：导入这个项目

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择当前文件夹：`/Users/mac/Documents/Codex/app_test`。
4. AppID 可以先选“测试号”或使用你自己的小程序 AppID。
5. 导入后点击“编译”。

## 第 3 步：先试用核心流程

1. 在“今日点菜”里搜索菜，点 `+` 加入今日菜单。
2. 点击“保存”，生成一条点菜记录。
3. 在“菜谱库”里新增、编辑、删除菜谱。
4. 在“记录”里查看以前吃过什么。

## 当前版本的取舍

- 数据只存在当前微信/开发者工具本地，换手机或换用户不会同步。
- 适合先验证“家里到底怎么用最顺手”。
- 如果后面要让家人和朋友共享同一个菜谱库，再接微信云开发数据库。

## 下一步建议

确认这个版本顺手以后，再做云端版：

1. 开通小程序云开发。
2. 新建 `recipes` 和 `orders` 两个集合。
3. 把 `utils/store.js` 里的本地存储函数替换成云数据库读写。
4. 加一个“家庭码”或“家庭 ID”，让小范围成员共享同一份数据。
