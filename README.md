# 家里吃什么

一个家用点菜、菜谱记录和食材库存管理小程序，适合自己家里或朋友小范围试用。

## 功能

- **食材库存**：像记账一样记录家里现有的食材。从超市购物回来后即可录入，记录购入日期、保质期、剩余量，并归类到「普通食材类 / 调味料类 / 冷冻类 / 水果类」。列表会自动标注临期、已过期状态，并支持「状态优先 / 按保质期最早」排序，顶部还有「N 样临期、M 样已过期，优先吃掉这些」的提醒横幅。
- **今日点菜（两种做法）**：
  - 方式一 · 选菜谱：从菜谱库选择常吃的菜，自动检查所需食材是否齐全。若有缺失，会提示缺几种，由你决定是否继续；确认后自动扣减本次消耗的食材，并记录到账。
  - 方式二 · 配食材：自己勾选库存里的食材、设置每样用多少，凑成一道自制菜，确认后同样自动扣减库存。
- **菜谱库**：以「食材 / 用量 / 单位」的结构化方式新增、编辑、删除常吃菜谱，食材会直接参与库存检查与扣减。
- **记录**：每顿饭吃了哪些菜、每种食材实际消耗多少、缺口多少，都自动记在这里。
- **扫小票批量录入**：在库存页点「扫小票」，拍照或选小票图片即可自动识别商品名并批量入库；没配 OCR 时也能直接把小票文字粘贴进来本地解析。适合从超市回来一次记一堆食材。
- **本地存储**：数据保存在本机/当前微信环境里。

## 第 1 步：安装工具

下载并安装微信开发者工具，然后选择「小程序」项目。

微信官方入口：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

## 第 2 步：导入这个项目

1. 打开微信开发者工具。
2. 选择「导入项目」。
3. 项目目录选择当前文件夹。
4. AppID 可以先选「测试号」本地预览；如果要上传体验版，需要使用真实小程序 AppID。
5. 导入后点击「编译」。

## 第 3 步：先试用完整流程

1. 在「食材库存」里录入刚买回来的食材（首次打开已带一些示例数据，可删除）。
2. 在「今日点菜」选「选菜谱」，点某道菜的「加入」，看它是否食材充足。
3. 在点菜页底部「本餐」清单点「确认开做」，在弹层里确认每种食材的本次用量（缺的部分可手动调整），确认后自动扣库存并记账。
4. 也可以选「配食材」，自己选几样食材凑一道菜加入本餐。
5. 在「记录」里查看这顿饭的消耗与缺口。

## 小程序后台设置建议

- 名称：`家里吃什么`
- 简介：`家庭菜谱、食材库存与点菜记账工具`
- 服务类目：`工具 / 备忘录`
- 头像：使用 `assets/avatar.png`

体验版只需要给家人或朋友添加「体验成员」，权限勾选「查看体验版」即可。

## 第 4 步（可选）：开启「扫小票」拍照识别

「扫小票」的粘贴文字解析是纯本地功能，开箱即用。如果想用**拍照自动识别**，需要走云开发 + 腾讯云 OCR：

1. 在微信开发者工具里开通「云开发」，记下环境 ID，填到 `app.js` 的 `CLOUD_ENV`。
2. 在 `project.config.json` 里加回 `"cloudfunctionRoot": "cloudfunctions/"`（本项目默认未启用，以免未开通云时启动超时）。
3. 在腾讯云控制台开通「文字识别 OCR」服务，拿到 SecretId / SecretKey。
3. 打开 `cloudfunctions/ocrReceipt` 目录，执行 `npm install` 安装依赖，然后右键该目录「上传并部署（云端安装依赖）」。
4. 在云函数 `ocrReceipt` 的环境变量里配置 `TENCENT_SECRET_ID` 和 `TENCENT_SECRET_KEY`（不要写进代码）。
5. 重新编译，库存页点「扫小票」→ 拍照即可识别。

> 不配置也能用：小票页下方「粘贴小票文字」可本地解析商品名，手动勾选后入库。

## 当前版本的取舍

- 数据只存在当前微信/开发者工具本地，换手机或换用户不会同步。
- 食材按名称匹配（忽略大小写与空格），所以菜谱里的食材名和库存里的要尽量一致。
- 扣减遵循「先买先吃」：同名称库存按购入日期早的优先消耗。
- 小票拍照识别依赖云开发与 OCR 密钥；粘贴文字解析为本地启发式提取，仅取商品名，数量/单位仍需手动补。
- 适合先验证「家里到底怎么用最顺手」。

## 下一步建议

确认这个版本顺手以后，再做云端版：

1. 开通小程序云开发。
2. 新建 `recipes`、`inventory`、`orders` 三个集合。
3. 把 `utils/store.js` 里的本地存储函数替换成云数据库读写。
4. 加一个「家庭码」或「家庭 ID」，让小范围成员共享同一份数据。
